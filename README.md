# My Python Paint (Tkinter Drawing App)

A lightweight desktop painting and drawing application built in Python using the `tkinter` GUI library. It provides an interactive canvas where users can sketch freely, switch between multiple colors, adjust brush thickness, erase mistakes, and clear the workspace.

## Key Features
- **Freehand Drawing:** Smooth continuous line rendering using mouse click-and-drag events (`<Button-1>`, `<B1-Motion>`, `<ButtonRelease-1>`).
- **Color Palette & Eraser:** Quick-select color buttons (`black`, `blue`, `green`, `red`, `yellow`, `purple`, `orange`) along with a dedicated `Eraser` mode.
- **Adjustable Brush Size:** Interactive horizontal slider (`Scale`) allowing brush widths from `1` to `30` pixels.
- **Workspace Reset:** One-click `Clear` button to wipe the canvas and start fresh.

## Technologies Used
- **Python 3**
- **Tkinter** (standard Python GUI toolkit)
